# Astoria Kava

Статичний сайт кавʼярні для GitHub Pages.

## Структура

```text
astoria-kava/
├─ index.html
├─ css/
│  └─ style.css
├─ js/
│  └─ main.js
├─ data/
│  └─ menu.json
└─ images/
   └─ hero-bg.png
```

## Як редагувати меню

Відкрийте файл:

```text
data/menu.json
```

Приклад пункту меню:

```json
{ "name": "Капучино", "price": "90 грн" }
```

## Як змінити фон

Замініть файл:

```text
images/hero-bg.png
```

Назву файлу краще залишити такою самою.

## Як запустити локально

У VS Code встановіть розширення Live Server, відкрийте `index.html` і натисніть `Open with Live Server`.
